# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Previous releases | ❌ |

Security fixes are applied to the latest release only. Keep Quartermaster up to date from the Marketplace.

## Reporting a Vulnerability

**Do not open a public GitHub issue.** Report it privately with GitHub's private vulnerability reporting: **Security → Advisories → Report a vulnerability** in this repository.

Include, where applicable:

- a description of the vulnerability;
- steps to reproduce;
- expected and actual behavior;
- relevant logs or a proof of concept, with personal data removed.

Reports are acknowledged within 72 hours, and a remediation or mitigation plan follows within 7 business days, depending on severity.

## Scope

This policy covers the Quartermaster integration code in this repository and the data it handles directly (inventory database, temporary images, channel events). Report issues in Home Assistant Core, AI providers, the Telegram bot integration, Alexa or other third parties to their maintainers.

## Responsible Disclosure

Do not share or exploit a vulnerability publicly before it is confirmed and fixed.
